Робот дизайны

Роботымыз LEGO SPIKE Prime-да құрастырылған. Робот UNEARTHED маусымының алаңындағы бағытты дәл жүріп өтуі үшін құрылымы ықшам әрі берік.

Құрылымы

  • Хаб: кіріктірілген гироскопы бар LEGO SPIKE Prime.
  • Жетек: жұптастырылған екі мотор (A және B порттары), шеңбер ұзындығы 17,5 см дөңгелектер.
  • Қондырмалар: қандай қондырмалар бар және қай миссияларға арналған…
  • Датчиктер: дәл бұрылуға арналған гироскоп, басқа датчиктер…

Робот бағыты

Алаңдағы миссиялар бірнеше жүріске бөлінген: сызбадағы әр түс — жеке жүріс, сандар — бағыт нүктелерінің реті.

Робот коды

Роботты LEGO SPIKE App-та Python тілінде бағдарламалаймыз. Кодымыздың ең бастысы — гироскоп арқылы дәл бұрылу.

🧩

Модульдік

Бұрылу мен қашықтықты градусқа айналдыру turn, turn50, turn100 және deg функцияларына шығарылған: оларды әр жүрісте қайта қолдану оңай.

🧭

Дәлдік

Бұрылар алдында робот гироскоп бұрышын нөлдеп, датчик тұрақталғанша күтеді, содан кейін қажетті бұрышқа дейін бұрылады.

⏱️

Жылдамдық па, дәлдік пе

Әр түрлі миссияларға жылдам бұрылу turn100 (жылдамдығы 400) және баяу әрі дәл turn50 (жылдамдығы 70) бар.

Бағдарламамыздан үзінді

from hub import motion_sensor, port
import motor_pair, runloop, sys, motor

motor_pair.pair(motor_pair.PAIR_1, port.A, port.B)

def deg(distance):
    # сантиметр → дөңгелектің бұрылу градусы (шеңбері 17,5 см)
    return int((distance / 17.5) * 360)

async def turn(rotation):
    motion_sensor.reset_yaw(0)
    await runloop.until(motion_sensor.stable)
    if rotation > 0:
        while motion_sensor.tilt_angles()[0] < rotation * 10:
            motor_pair.move_tank(motor_pair.PAIR_1, -200, 200)
        motor_pair.stop(motor_pair.PAIR_1)
    if rotation < 0:
        while motion_sensor.tilt_angles()[0] > rotation * 10:
            motor_pair.move_tank(motor_pair.PAIR_1, 200, -200)
        motor_pair.stop(motor_pair.PAIR_1)

async def turn50(rotation):
    motion_sensor.reset_yaw(0)
    if rotation > 0:
        while motion_sensor.tilt_angles()[0] < rotation * 10:
            motor_pair.move_tank(motor_pair.PAIR_1, -70, 70)
        motor_pair.stop(motor_pair.PAIR_1)
    if rotation < 0:
        while motion_sensor.tilt_angles()[0] > rotation * 10:
            motor_pair.move_tank(motor_pair.PAIR_1, 70, -70)
        motor_pair.stop(motor_pair.PAIR_1)
